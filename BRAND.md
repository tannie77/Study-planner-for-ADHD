# Studyvella brand direction

Studyvella is for the student with a full agenda who still wants a clear head. The brand should feel capable, composed, and decisive. The inspiration is high output with strong personal presence; the product experience should make a busy day feel manageable.

## Visual system

| Role | Choice |
| --- | --- |
| Primary type | Times New Roman throughout the interface |
| Display type | The Seasons for expressive headlines when a licensed font file is supplied; Georgia is the current fallback |
| Mauve | `#805F79` |
| White | `#FFFFFF` |
| Black | `#171217` |

Light and dark mauve tints are derived from the same primary mauve. Use clear borders, generous white space, sharp corners, and editorial typography. Avoid visual clutter and competing accent colors.

## Voice

- Speak to someone ambitious and busy without implying they should do everything at once.
- Be direct and calm: *“A lot to do. A clear way through.”*
- Show the next action: *“Start with the next move.”*
- Celebrate progress without pressure: *“One move, handled.”*
- Explain the product in concrete terms: tasks, focus blocks, and the Tomorrow Test.

The affirmation strip uses first-person statements about calm work and study. It scrolls above the headline on both the landing page and dashboard, pauses on hover or keyboard focus, and stays still when reduced motion is preferred.

The celebrity references are moodboard inspiration for work ethic and presence. The website does not use their names, likenesses, or imply an endorsement.

## Font handoff

The Seasons is not in the repository or installed on this development machine. The site currently uses Georgia for display accents where The Seasons would appear. To make the exact font consistent for every visitor, add a properly licensed webfont file and declare it with `@font-face` in `frontend/css/brand.css`.
